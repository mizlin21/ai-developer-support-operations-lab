# Developer Support Tickets

This folder contains simulated developer support tickets for the AI Developer Support Operations Lab.

The tickets represent realistic technical support scenarios involving:

- API authentication failures
- webhook delivery issues
- SDK configuration errors
- production API timeouts
- rate limiting
- integration sync failures

These tickets will be used by later phases of the lab for:

- classification
- troubleshooting
- log correlation
- knowledge retrieval
- escalation decisions
- operational reporting

The dataset is intentionally structured to support repeatable testing and evidence-driven AI workflows.
